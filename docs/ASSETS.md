# Asset provenance

The Briefstamp identity, interface composition and proof-path illustration were authored for this project. The interface uses Lucide icons, Motion for React, DM Sans and Space Grotesk. The same Google Fonts are now self-hosted from `public/assets/fonts` under their adjacent SIL Open Font Licenses. The download URLs, sizes and hashes are in [font provenance](../public/assets/fonts/provenance.json). There are no runtime Google Fonts requests. The production landing component is also rendered into the build's HTML so its content is readable with scripts disabled; this is the same public page, not an audit fixture.

The marketing landing page includes original ImageGen artwork of a cobalt delivery folio, paper reports and a glass browser panel. It is a conceptual illustration, not a product screenshot, client website or customer evidence. Optimized desktop and mobile WebP files are packaged in `public/assets`; the exact generation prompt and provenance are in [landing asset notes](LANDING_ASSET.md). The favicon and proof-chain diagram are locally authored SVG graphics.

The Forma Studio website is an explicitly synthetic acceptance-test fixture. Its studio identity, Common Ground artwork, copy and SVG composition were authored locally. It does not depict a client, customer endorsement or real delivered project. Screenshot evidence is captured by real Playwright Chromium execution of this synthetic HTML. No stock photos or generated photographs were used.

User-facing screenshots and the walkthrough are recordings of the actual app. They are not visual mockups and do not establish a public deployment, a real client website audit or a hackathon submission.
