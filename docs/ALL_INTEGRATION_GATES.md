## Free-provider budget proof

The [shared allowance guard](../server/providers/free-resource-policy.ts) requires private account-specific proof checked within 24 hours, expiry, the exact API-key hash, allowed operations and persisted unit/call reservations. Failures consume reservations. Other optional providers still require confirmed-free proof. Backboard additionally permits explicitly approved existing credits, capped at $0.03, with no card/auto-reload and one write/one search. Its [hosted helper](../server/hosted-backboard.ts) requires an operator token and exclusive-creates a file identified by the exact key/assistant/proof; it never overwrites spent counters. A free host's disk replacement loses local state, so this is not a durable cross-deployment budget. A restart is not permission to regain an exhausted allowance.

Official public offers checked today: [Backboard](https://backboard.io/pricing) lists a no-card Free tier with starter memory credit and trial memory/RAG; [SerpApi](https://serpapi.com/pricing) lists 250 free monthly searches; [ElevenLabs](https://elevenlabs.io/pricing) lists 10,000 free credits with the commercial license beginning on a paid tier. These facts establish possible free paths, not permission to run against an unverified balance. The October 15 application-smoke Tinker sampler, separate from the frozen October 14 benchmark, was explicitly renewed to October 19 23:59:30 UTC; its inference allowance expires earlier and the frozen comparison checkpoints remain separate. Keep each route disabled until its own proof exists. Native Gemma has a separate fixed-model free-pricing check and fixed synthetic/public-homepage consent routes; its actual hosted proof is linked above, with configuration expiry on October 20.

## Entire: narrow local Codex provenance

[Entire's CLI is MIT-licensed](https://github.com/entireio/cli). The [Codex integration](https://docs.entire.io/agents/codex) supports retrospective imports from the last 30 days. Normal future capture writes `.codex/hooks.json` and requires Codex hooks; that is unnecessary for this scoped import. A repository with a resolvable commit is required. The current session must belong to this repository by its recorded working directory.

The official **v0.11.4** [import command](https://github.com/entireio/cli/blob/v0.11.4/cmd/entire/cli/import_cmd.go) exposes `--path`, `--session` and `--dry-run`. Its [Codex importer](https://github.com/entireio/cli/blob/v0.11.4/cmd/entire/cli/agentimport/codex.go) accepts an exact JSONL file as the walk root, so it need not enumerate the other sessions. Use the exact current rollout file, not the global session directory:

```sh
# Equivalent selection used by the verifier; supply the authorized exact values.
work/tools/entire/entire import codex \
  --path /absolute/path/to/the-current-rollout.jsonl \
  --session THE-EXACT-AUTHORIZED-SESSION-UUID --dry-run

# Only after the dry run identifies exactly one intended session:
work/tools/entire/entire import codex \
  --path /absolute/path/to/the-current-rollout.jsonl \
  --session THE-EXACT-AUTHORIZED-SESSION-UUID
```

This is an import performed afterward, not proof that Entire captured the original work live. It writes local checkpoint/session metadata, does not call `enable`, and does not itself push. The implementation may read remote checkpoint ref names for deduplication; do not describe it as network-free. Do not use `session attach`, which has remote synchronization behavior, or generated explanations, which can invoke a model provider. The [successful verifier](ENTIRE.md) used isolated configuration, disabled telemetry/auto-update, and read only the selected current session's stable snapshot.

Verified official release assets:

- [macOS ARM64 archive](https://github.com/entireio/cli/releases/download/v0.11.4/entire_darwin_arm64.tar.gz): 20,642,356 bytes; SHA-256 `6636dd5bf1b2ff9a9c52d4ea1ad936799ada962142f0f5e5c3c8611f3acd347b`.
- [Official checksums](https://github.com/entireio/cli/releases/download/v0.11.4/checksums.txt) and [release metadata](https://api.github.com/repos/entireio/cli/releases/tags/v0.11.4) independently returned that digest. The actual archive was verified and the executable extracted into the ignored workspace; no global installer was run.

The proof should retain tool version, archive digest, imported session count, checkpoint IDs, import time, source revision and one concrete design decision traced to the imported work. Publish a reviewed minimal receipt, not the transcript, account identity or screenshots from private consoles. [Entire's security documentation](https://docs.entire.io/security) explicitly notes that assets/images are unscanned and PII protection is optional. Automatic redaction is not publication approval. A local import by itself is not a public Entire session link or hosted search proof.
