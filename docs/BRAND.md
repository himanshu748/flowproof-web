# Briefstamp

Briefstamp turns a client brief into approved website checks and a delivery report backed by observed evidence.

The name combines the starting brief with the delivery stamp. A stamp refers to the report and its traceable checks; it does not certify an entire website or imply that unavailable checks passed.

The product was renamed from FlowProof on 14 October 2026. An existing [Flowproof testing product](https://www.flowproof.dev/) overlaps with browser testing and client handoffs. Exact-name web searches for Briefstamp found no indexed software product at the time of review. Domain availability and trademark clearance have not been verified; no domain was purchased.

The interface, page title, reports, downloaded files and current documentation use Briefstamp. Existing repository and demo URLs, authentication headers, environment variables, database tables and historical experiment receipts retain their original identifiers for compatibility and provenance. The audit workflow accepts both `briefstamp-plan.json` and previously exported `flowproof-plan.json`.

The rename does not change integration readiness. The Shared Free Tiger service still requires an authenticated CA certificate and fingerprint. A separate isolated no-card trial probe has verified the application store and retrieval over strict TLS; public demo database persistence remains disabled. Recorded Tinker results remain a small agent-reviewed pilot, and LoRA did not outperform few-shot prompting.
